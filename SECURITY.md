# Security Policy

## Supported versions

Only the latest released version receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue. Email **kabil.gannoun@ept.ucar.tn** with a
description, reproduction steps and the affected version. You can expect an
acknowledgement within a few days and a fix or mitigation plan once the report is
confirmed. Please allow time for a release before public disclosure.

## Scope notes

archdoc analyses source text statically and never imports or executes the code it
reads. Reports about crashes or excessive resource use on crafted input files are in
scope.
